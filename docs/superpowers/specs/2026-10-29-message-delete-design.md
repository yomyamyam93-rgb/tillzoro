# 메시지 삭제: 두 갈래와 사라지는 모션

2026-10-29

## 왜

지금 삭제는 하나뿐이고, 내 글만 지울 수 있고, 한 번 더 누르면 빨간 "모두에게서 삭제"로 바뀐다.
두 가지가 아쉽다.

1. 상대의 글을 내 화면에서 치울 방법이 없다. 신고 말고는 선택지가 없다.
2. 지워질 때 거의 아무 일도 일어나지 않는다. 180ms 동안 살짝 흐려지고, 빈 자리는 뚝 닫힌다.

## 무엇을

### 1. 삭제를 두 갈래로

| 대상 | 메뉴 |
|---|---|
| 내 글 (서버에 있음) | 나에게만 삭제 · 모두에게 삭제 |
| 내 글 (보내는 중·못 보낸 것) | 삭제 — 보내기를 멈추고 치운다 |
| 상대 글 | 신고 · 나에게만 삭제 |

- **빨간색을 쓰지 않는다.** 두 항목 모두 보통 색이다.
- **확인 단계를 두지 않는다.** 항목이 이미 갈라져 있으니 누르면 바로 지운다.
- 지우는 항목은 메뉴 맨 아래에 둔다. "나에게만"이 위, "모두에게"가 아래다.

**나에게만 삭제**는 서버를 건드리지 않는다. 지운 id를 `hide:<방>`에 남기고 이 기기에서만 감춘다.
이 저장소는 이미 있고([index.html:1179](../../../index.html)), 서버에서 다시 받아올 때 걸러내는 쪽만
구현돼 있었다. 쓰는 쪽을 이번에 붙인다.

### 2. 빨려들며 사라지는 모션

말풍선이 제자리에서 한 점으로 모이며 사라지고, **동시에** 그 높이만큼 아래 글들이 올라와 자리를 메운다.
지금 빠져 있는 건 사라짐이 아니라 이 자리 메우기다.

```
말풍선   scale(1) → scale(.52), opacity 1 → 0
자리     height → 0, margin-bottom → -3px (.days 의 gap 을 상쇄)
시간     240ms
곡선     cubic-bezier(.45,0,.75,.25) — 처음 천천히, 끝에 빨려들듯
```

`prefers-reduced-motion`이 켜져 있으면 지금처럼 즉시 치운다. 기존 규칙 그대로다.

## 손대는 곳

- `.leave` CSS — 모션 교체
- `dropMsg()` — 높이를 재서 0으로 줄인다
- `msgMenu()` — 항목 구성
- `hideMsg()` — 새로 추가
- 2단계 확인(`twoStep`·`.sure`) — 삭제

## 다 됐다고 할 수 있는 조건

1. 내 글을 길게 누르면 "나에게만 삭제"와 "모두에게 삭제"가 보이고, 어느 쪽도 빨갛지 않다
2. 상대 글을 길게 누르면 "나에게만 삭제"가 보인다
3. "나에게만 삭제"한 글은 앱을 껐다 켜도, 서버에서 다시 받아와도 보이지 않는다
4. "모두에게 삭제"한 글은 상대 화면에서도 사라진다
5. 지울 때 말풍선이 줄어들며 사라지고 아래 글들이 부드럽게 올라온다
6. 동작 줄이기가 켜져 있으면 모션 없이 즉시 사라진다

## 하지 않는 것

- 삭제 취소(되돌리기)
- 감춘 글을 다시 보는 화면 — 사라진 것을 보관하는 화면은 뺄셈이 아니다 (R-5.7)
- `hide:` 목록 정리 — 방이 Zero 로 끝나면 어차피 방 데이터와 함께 사라진다
